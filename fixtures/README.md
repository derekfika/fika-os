# Fixtures

Fixtures contain invented, non-production examples only. They must never contain private customer data, production identifiers or secrets.

## Current fixture sets

- [`pack-1`](pack-1/) — valid and deliberately invalid examples for the Draft Pack 1 schemas.
- [`bookings`](bookings/) — existing Draft FikaBooking evidence; not adopted.

Pack 1 fixtures are validated with `python scripts/validate-pack-1-schemas.py`.
