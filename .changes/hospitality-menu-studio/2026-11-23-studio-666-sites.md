# 2026-11-23 — Edit catalogue sites and booking services in Studio

Catalogue managers can change site-wide product permission and price, VAT, minimum, quote mode and wording overrides. Company and site booking service layouts can be ordered, hidden, restored to inheritance and reviewed for category renames. Commands carry Hub Item and layout revisions, with a separate event-date availability check.

Validation: Studio unit tests, TypeScript, production build and local Chromium fixtures at laptop, tablet and narrow widths.
Deployment: none.
