# 2026-11-01 — Hub Development dashboard (read-only v1, #241)

Adds an owner-only **Development** entry to the Hub (sidebar and launcher) and a read-only `/development` dashboard backed by `GET /api/development`. The API is admitted server-side exactly like the Usage Observatory (`requireAuthmodAdminContext`: active person AUTHMOD Administrator) and fails closed with 401/403 and no metadata. A server-only data layer (`lib/development`) reads GitHub issues, pull requests and check runs with a credential taken from server environment (`FIKA_DEV_DASHBOARD_GITHUB_TOKEN`, optional `FIKA_DEV_DASHBOARD_GITHUB_REPO`) that is never exposed to the browser; with no credential the snapshot is `unavailable`. Snapshots are cached (60s, single-flight), bounded (one page of issues and PRs, at most 20 CI lookups), rate-limit aware, and carry `lastVerified` plus stale/partial/unavailable/error flags. The lifecycle Started, Coded, Tested, Merged, Deployed to staging, UAT accepted, Production live is derived step by step from evidence with source, time and link; merge never implies deployment and deployment never implies UAT. Release/serving provenance, the UAT register and governed workspace status are not connected in v1 and show "Not connected". There are no close, sign-off or deploy actions.

Validation: node:test suite `tests/development/development.test.ts` (auth fail-closed, stale/partial/unavailable flags, lifecycle no-over-claim, no credential in payloads), Hub typecheck and `next build`; exact results are in the PR.
Deployment: none. Server credential wiring (secret and App Hosting config) is a separate governed follow-up.

Review fixes (PR #242): PRs link to issues only via closing keywords or an `issue-N` branch; an open linked PR outranks a merged slice (shown as partially merged); production evidence matches the merge commit only; unlabelled issues never match an app-specific deployment; refresh failures (including 401/404/network/secondary 403/unparseable reset) back off for a cooldown; not-planned/duplicate closures are not "unverified"; closed-unmerged PRs are not "Coded"; only https://github.com/ links render; repo names with `.`/`..` segments are rejected; tabs expose `aria-pressed`. Validation: 28 focused tests pass, tsc, eslint, next build.
