# 2026-11-18 — Export saved and unpublished Menu Planner days/weeks (#585)

Adds a read-only **Export menu** action to the Week Planner. Operators can select one or more days across existing available weeks, including published, partially published and unpublished menus. The Excel-compatible UTF-8 CSV preserves full dish names, recorded portions, destination allocations and the shared canonical presentation order. Empty selected days remain represented.

Other selected weeks load through the existing authenticated, OPLOC-scoped read API; current unsaved browser edits are explicitly labelled. CSV formula-looking text is escaped. Export never writes to weeks, publication state, CPU, Delivered-In or allergen declarations.

Validation: new menu-export unit tests plus the Menu Planning typecheck/build and protected PR gate. Deployment: pending governed staging and Menu Planning-only production release; no production writes in this change.
