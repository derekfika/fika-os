# 2026-10-30 — Week Planner dish-picker filters by tags, category and salad slot (#155)

The Week Planner dish picker gains a **Filters** panel: multi-select tag filter (with its own search), category filter and salad-slot filter, with per-option counts, removable chips, a live "Showing X of Y" count, a **Reset filters** action and distinct empty states (nothing offered for the slot, filters hiding everything, or a search with no match). Values within one group match any; separate groups combine with AND. Filters only narrow what the slot already offers: the slot's category rule and the salad-slot rule (a classified salad appears only in its own subtype's slot; unclassified salads stay offered in SALAD 1–5; SALAD 6 FIKA Seasonal is explicit only) always apply first, so a filter can never pull a dish into the wrong slot. Search now matches canonical dish names and aliases (not tags or category text); an alias-only match is listed after the ranked results. Options are built from the shared tag registry (#152) and from the dishes the slot offers, so no tag is hard-coded and no filter lists a choice that would return nothing. Filters live with the search text, so Cancel from the Create/Edit Dish modal returns to the same filtered picker, and they reset each time a cell's picker is opened.

Unchanged: single-click selection, Enter-to-create and the #154 modal, drag/drop copy, clear, portions, allocations, publication, and every stored dish, tag and subtype (filters are read-only; nothing is reclassified or written). Removing the per-row Edit buttons in favour of a right-click menu is #186 and is not part of this change.

Validation: Menu Planning typecheck, 13 new tests and the full Menu suite, and governed validation; see the PR. Not checked in a browser (the local Menu app cannot load the planner without its authentication service) or on staging.
Deployment: none.
