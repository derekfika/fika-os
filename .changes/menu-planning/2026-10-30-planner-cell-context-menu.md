# 2026-10-30 — Week Planner cell context menu replaces the picker Edit buttons (#186)

Right-click on a populated Week Planner dish opens a compact FIKA context menu: **Edit dish** (the #154 modal for that cell's canonical dish, opened directly without the picker), **Change dish** (the normal picker for that cell), **Copy to another day** (the existing copy dialog), a divider, and a red **Clear from planner** (the existing clear command). The repeated per-row **Edit** buttons are removed from the dish picker. Single click still opens the picker and there is no double-click behaviour.

Interactions: `contextmenu` is prevented only on populated planner cells, so the browser menu remains on inputs, links and empty cells. The menu opens at the pointer and flips/clamps inside the viewport; Shift+F10 or the Menu key opens it for the focused cell; ArrowUp/Down/Home/End move, Enter or Space activate, Escape or a click elsewhere close it without acting and return focus to the cell. Touch uses a long press (cancelled by movement so scrolling and drag are unaffected) and a compact "⋯ More actions" button in the cell actions, so nothing depends on right-click. The click that follows opening the menu is ignored so the picker never opens behind it. Nothing is written until an item is explicitly activated; actions read the cell's own day, slot and canonical dish ID at activation time.

Honest limits: **View dish details** is not offered because the Dish Library has no read-only detail view that can be opened by dish ID (adding one would be a new feature). Edit is shown disabled, with the reason, when the cell's dish is not in the Dish Library any more or has no dish ID, rather than editing the wrong record. Renaming a dish still does not rewrite the label already stored on planner entries. The reference image (Drive) was not opened; the visual treatment follows the written description in the issue and existing FIKA tokens.

Validation: Menu Planning typecheck, 17 new unit/contract tests, 10 new Playwright browser tests against the local app with a fixture API (real Chromium, writes recorded), the 7 existing Playwright planner/spellcheck tests (drag/drop and copy unaffected), the full Menu suite, and governed validation; see the PR. Not checked on a physical touch device or on staging.
Deployment: none.
