# Pack 5 Reflection

## What this pack clarified

The Event domain owns a bespoke activity with one mandatory Event Contact and remains distinct from Service, Service Arrangement, recurring schedules and Hospitality Booking. An Event may reference an existing Client, Services and Service Arrangements without transferring domain ownership.

## Unresolved concepts

- Event lifecycle status catalogue.
- Publication approval authority and rules.
- Approval thresholds, notification thresholds and escalation rules.
- Additional approval-evidence requirements.
- Detailed OPREL modelling, which remains outside Pack 5.

## Workflow observations

None recorded. Workflow v2.0 was treated as frozen.

## Lessons

The resolved gates establish mandatory Event Contact and approval records while preserving optional Client participation. Lifecycle, publication and threshold policy remain outside the schema pending future business authority.
