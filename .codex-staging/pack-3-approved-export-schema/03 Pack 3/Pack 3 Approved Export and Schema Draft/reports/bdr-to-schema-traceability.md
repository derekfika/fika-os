# Pack 3 BDR-to-Schema Traceability

| Schema | Source BDRs | Boundary protected |
|---|---|---|
| `equipment-allocation.schema.json` | SVC-009 | Allocation of an Equipment asset to a Service Arrangement or Event for a time and location. |
| `recurring-schedule.schema.json` | SVC-002, SVC-005, SVC-007 | Repeating pattern of planned delivery for a Service Arrangement. |
| `recurring-schedule-exception.schema.json` | SVC-005 | Approved amendment, pause or cancellation for a schedule date or period. |
| `requested-work-input.schema.json` | SVC-006, SVC-005 | Demand input into the shared fulfilment workflow while preserving source classification. |
| `service.schema.json` | SVC-001, SVC-002, SVC-008 | Durable reusable offering that FIKA provides. |
| `service-arrangement.schema.json` | SVC-002, SVC-004, SVC-007, SVC-010 | OPLOC-specific way a Service is provided within one operational scope. |
| `service-commercial-ownership.schema.json` | SVC-010 | Role-based commercial ownership and delegated responsibility for a Service or Service Arrangement. |
| `service-domain-dependency.schema.json` | SVC-003 | Dependency from a Service Arrangement to a supporting domain capability without transferring ownership. |
| `service-event-reference.schema.json` | SVC-008 | Relationship showing an Event uses, references or purchases Services without becoming a Service Arrangement. |
