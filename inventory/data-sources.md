# Data Source Inventory

## CPU Production Dashboard sources

| Data source | Type | Purpose | Source-of-truth classification | Confirmed limitations |
|---|---|---|---|---|
| CPU-scanned hospitality and delivery events | Google Calendar | Current discovery envelope, timing, attachments, site context and delivery schedule | Integration source; not canonical booking authority | Cancelled events are skipped; canonical cancellation propagation is not demonstrated |
| Booking JSON, quote and legacy booking-form attachments | JSON and Google/Microsoft Office files | Booking facts and menu lines, with JSON preferred | JSON may project authoritative facts; documents are legacy evidence | Current JSON adapter predates draft `FikaBooking` v1; failures become warnings |
| CPU Orders | Google Sheet | Normalised production projection, warnings, changes and prep/photo state | Operational projection only | Calendar-event identity; lossy line items; no stable product IDs or units |
| CPU Deliveries | Google Sheet | Separate projection of recognised delivery events | Operational projection only | No canonical booking/production-order link found |
| CPU Scan Log and scan jobs | Sheet and Script Properties | Scan summaries and temporary chunk progress/errors | Audit/runtime support only | Summary log is not an immutable record-level history |
